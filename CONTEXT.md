# CONTEXT — словарь проекта SkillHub

| Термин | Значение |
|---|---|
| **Скилл** | Каталог с `SKILL.md`: YAML front-matter (`name`, `description`, `caption`) + тело Markdown, которое становится системным промптом при выборе скилла |
| **Классификатор** | Внешняя модель, которая по `description` всех скиллов (обрезка ~250 символов) выбирает один или ни одного |
| **Намерение (`intent`)** | Короткая задача пользователя; единственный пользовательский текст, который видит классификатор |
| **Материал (`material`)** | Недоверенный текст для обработки выбранным скиллом; не участвует в выборе режима |
| **Транскрипция** | Сырая расшифровка совещания в поле `material` при работе режимов встречи |
| **Progressive disclosure** | В контекст модели попадают только описания; тело — после выбора; подфайлы (`references/`) — по мере надобности |
| **Реестр** | `SkillRegistry`: сканирует каталог скиллов, валидирует и публикует одно поколение `RegistryCapture`; `reload()` не пересоздаёт объект |
| **Поколение** | `RegistryCapture`: неизменяемые отчёт и снимок одной публикации; `capture()`, `snapshot` и `search()` читают одну ссылку без блокировки |
| **Снимок** | Неизменяемое `Mapping[str, Skill]` внутри текущего поколения; отдельно от отчёта не публикуется |
| **Окно ассистента** | Главная страница `GET /`: поля намерения и материала, бейдж выбранного режима и список режимов только для чтения |
| **`GET /`** | Серверная HTML-страница окна ассистента |
| **`POST /api/assistant`** | JSON-исход окна: прикладные поля `intent` и `material`; успех возвращает выбранный режим и текст |
| **Каталог** | Страница «Скиллы» (`GET /skills?q=`) и `GET /api/skills?q=`; оба читают текущее поколение реестра |
| **Перезагрузка каталога** | `POST /skills/reload` с секретом CSRF и точным Origin; успешный итог показывается одноразово после перенаправления, отказ — HTML-предупреждение на той же странице |
| **Битый скилл** | Скилл, не прошедший валидацию (нет `description`, description > 1024, имя не kebab-case или > 64, пустое тело, нет `SKILL.md`); пропускается с `WARNING`, остальные загружаются |
| **`has_files`** | В каталоге скилла есть хотя бы один файл кроме `SKILL.md` (рекурсивно); пустые каталоги не считаются |
| **Протокол** | Структурированный результат работы скилла: тема, дата, участники, обсуждение, решения, задачи, открытые вопросы |
| **Черновик протокола** | Валидный `Protocol` после модели, но до ответов или явных пропусков по всем уточнениям |
| **Уточнение (`Clarification`)** | Типизированный вопрос к конкретному отсутствующему полю с состоянием `pending`, `answered` или `skipped` |
| **Отменить выбор** | Вернуть строку уточнения из `answered`/`skipped` в `pending`, разблокировав поле |
| **Финализация** | Серверная проверка, что каждое уточнение отвечено или пропущено, и применение ответов к итоговому `Protocol` |
| **Грамматика v1** | Формальные правила Markdown-формата протокола, файл `skills/meeting-protocol/references/protocol-format.md` |
| **Заполнитель** | `—` (U+2014) — единственный литерал пропуска в протоколе; в docx превращается в «Не назначен» / «Не определён» / «Раздел не заполнен» |
| **Структура vs наполнение** | Нарушение структуры (лишний заголовок, не три колонки) — `ProtocolParseError`; пустой раздел или `—` — данные, не ошибка |
| **Roundtrip** | Инвариант `parse(render(p)) == p`, проверяется property-based тестом |
| **Соседний скилл** | Реальный режим с близкой границей выбора; нужен для проверки, что классификатор отличает протокол от задач, резюме и перевода |
| **e2e-демо** | `eval/run_e2e.py`: транскрипция → DeepSeek с телом скилла → парсер → уточнения → `.docx` в `examples/` |
| **Обработчик скилла (`SkillHandler`)** | Разрешённый конфигурацией Python-обработчик; файлы каталога сами не исполняются |
| **Общий текстовый обработчик (`PromptSkillHandler`)** | Безопасный обработчик простых режимов: тело выбранного `SKILL.md` + материал → текстовый ответ без инструментов |
| **Шлюз модели (`LlmGateway`)** | Типизированная граница вызова поставщика модели; возвращает текст, причину завершения и фактическое использование токенов |
| **Журнал использования** | SQLite-таблица технических метаданных модельных вызовов и стоимости; содержимое встреч не хранит |
| **Снимок тарифа** | Цены, применённые к конкретному вызову и сохранённые вместе с ним; будущая правка YAML не меняет историю |
| **Fail-closed** | Ошибка классификации, валидации, лимита или безопасности останавливает сценарий вместо небезопасного запасного поведения |
