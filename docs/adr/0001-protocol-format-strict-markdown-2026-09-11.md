# ADR 0001. Формат протокола — строгий Markdown с формальной грамматикой

Дата: 2026-09-11
Статус: принято

## Контекст

Скилл «Протокол встречи» выдаёт протокол, который пользователь читает в чате и выгружает в Word. Конвертер по заданию должен разбирать ответ «однозначно, без эвристик». Формат — общий контракт скилла (часть 1), конвертера (блок Б) и API (часть 2).

## Варианты

1. **Строгий Markdown**: H1 с фиксированным префиксом, две строки метаданных, четыре H2 в фиксированном порядке, задачи — таблица ровно из трёх колонок, единственный литерал пропуска `—`.
2. **JSON / YAML по Pydantic-схеме**: тривиальный парсинг, схема как контракт.
3. **Гибрид**: Markdown для человека плюс fenced-JSON «машинная копия».

## Решение

Вариант 1. Промежуточное представление — Pydantic-модель `Protocol`; парсер `Markdown → Protocol`, рендер `Protocol → Markdown`, генератор `Protocol → docx`. JSON отдаётся через API из уже проверенной модели.

## Обоснование

- Просьба выдать JSON снижает качество текста и рассуждения ещё до constrained decoding; на длинных документах структурный режим уменьшает и валидность, и точность (ExtractBench, 2026: валидность 51% → 37%). Протокол — длинный текст с цитатами и решением «кто отвечает».
- Валидный JSON не гарантирует верных значений (разрыв 15–30 пунктов между «распарсилось» и «значения верны» — Structured Output Benchmark, 2026). Главный риск — выдуманный ответственный или срок — решается правилами в теле скилла, не форматом.
- Markdown нативен для модели и читаем в чате; строгая грамматика делает парсер детерминированным: любое отклонение структуры — ошибка с номером строки, а не догадка.
- Гибрид создаёт два источника истины и риск их рассинхрона.

## Следствия

- Грамматика живёт в одном файле `skills/meeting-protocol/references/protocol-format.md`; тело скилла её включает, парсер реализует, пример — фикстура тестов.
- Граница строгости: структура — контракт (ошибка), наполнение — данные (заполнитель).
- Roundtrip-свойство `parse(render(p)) == p` — страж дрейфа между рендером и парсером.
- Изменение формата = новая версия грамматики (v2) и правка трёх мест: файл грамматики, парсер, тесты. Скилл ссылается на версию.
