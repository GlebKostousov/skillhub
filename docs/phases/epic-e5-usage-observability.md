# E5. Стоимость и наблюдаемость

Статус: принят. As-built: тарифы YAML, `UsageLedger`, `MeteredLlmGateway`, `GET /usage` и `GET /api/usage`.
Вес: 8 единиц
Зависит от: E2

## Результат

Пользователь видит токены и стоимость запроса, историю и дневной итог. Владелец может ограничить расходы, а логи объясняют жизненный цикл запроса без раскрытия текста встречи.

## Слайс E5-S1. Модели и тарифы — 2 единицы

Ценность: модель, лимиты и цена меняются через конфигурацию без правки бизнес-логики.

Входит:

- типизированный YAML;
- input/output price per million tokens;
- model, max_tokens, timeout, temperature;
- safe_load, fail-fast и запрет неизвестных полей;
- источник и дата тарифа в README.

Приёмка: неизвестная модель/поле и отрицательная цена останавливают запуск; секретов в YAML нет.

## Слайс E5-S2. Точный ledger — 2 единицы

Ценность: история расходов не меняется задним числом после изменения тарифа.

Входит:

- SQLite только для usage;
- Decimal до записи, integer money scale;
- token counts, operation, skill, model, tariff snapshot, request ID;
- миграция и параметризованные запросы.

Приёмка: расчёт округляется один раз по документированному правилу; рестарт сохраняет историю; пользовательский content в базе отсутствует.

## Слайс E5-S3. Дневной бюджет — 2 единицы

Ценность: приложение не начинает вызов, который превышает установленный предел.

Входит:

- worst-case reservation;
- committed/reserved/released;
- атомарность SQLite;
- освобождение резерва после ошибки;
- отдельный classifier и generation usage.

Приёмка: параллельные запросы не обходят лимит; отказ поставщика не навсегда съедает резерв; превышение останавливается до HTTP-вызова.

## Слайс E5-S4. Логи и экран расходов — 2 единицы

Ценность: пользователь видит цену текущего запроса и агрегированную историю.

Входит:

- request ID сквозь web → classifier → handler → ledger;
- structured events без intent/material/output;
- вкладка «Расходы»;
- current request, сегодня, последние записи;
- отображение n/a при неизвестном usage.

Приёмка: один запрос прослеживается по request ID; лог содержит длительность, статус и стоимость, но не контент; UI и SQLite дают одинаковый итог.

## Риски

- Decimal не должен скрыто превращаться в float.
- Снимок тарифа обязателен: пересчёт старой истории по новому конфигу запрещён.
