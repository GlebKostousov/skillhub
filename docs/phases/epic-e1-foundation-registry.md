# E1. Каркас и каталог скиллов

Статус: не начат
Вес: 8 единиц
Зависимости: нет

## Результат

Приложение запускается без ключа DeepSeek. Пользователь открывает веб-страницу, видит пять режимов, ищет их по имени и подписи. Битые каталоги пропускаются с безопасным предупреждением.

## Слайс E1-S1. Запускаемый каркас — 2 единицы

Ценность: открывается главная страница и health endpoint.

Входит:

- Python 3.13, uv и минимальные зависимости;
- `app_factory.py` как composition root;
- Jinja2, локальная статика и простой Bootstrap-каркас;
- базовые `SkillHubError`, централизованный HTTP handler и structlog;
- начальные Ruff, mypy strict, import-linter и pytest.

Не входит: бизнес-сценарии, DeepSeek, SQLite.

Приёмка:

- приложение запускается одной документированной командой;
- без `.env` нет небезопасных fallback;
- корневая страница и health отвечают;
- core не импортирует прикладные пакеты;
- базовый quality gate зелёный.

## Слайс E1-S2. Валидация реестра — 2 единицы

Ценность: ассистент безопасно обнаруживает корректные скиллы.

Входит:

- front-matter и тело `SKILL.md`;
- name из файла или имени папки;
- kebab-case, длины 64/1024, обязательный description, непустое тело;
- `has_files`;
- безопасный YAML, предел размера и containment path;
- warning с путём и причиной, без тела файла.

Приёмка: все обязательные позитивные и негативные случаи задания проходят; один битый скилл не влияет на остальные.

## Слайс E1-S3. Снимок, reload и поиск — 2 единицы

Ценность: новые скиллы появляются без пересоздания реестра, чтение не прерывается.

Входит:

- неизменяемый copy-on-write snapshot;
- сериализация конкурирующих reload;
- lock-free read;
- поиск case-insensitive по name и caption;
- отчёт loaded/skipped.

Приёмка: четыре читателя и повторные reload не видят частичное состояние; поиск даёт стабильный порядок.

## Слайс E1-S4. Пять скиллов и каталог — 2 единицы

Ценность: в API и интерфейсе видны пять настоящих режимов.

Входит:

- валидные `meeting-protocol`, `meeting-action-items`, `text-summary`, `text-translation`, `business-message`;
- обязательный `GET /skills?q=`;
- страница «Скиллы» с caption, name, description и has_files;
- кнопка reload с понятным результатом.

Приёмка: каталог показывает ровно пять режимов; фильтр работает; reload не очищает корректный список при битом шестом каталоге.

## Риски

- Слишком раннее разрастание core: допускаются только конфигурация, ошибки, логи и web security baseline.
- Динамическое исполнение: каталог содержит данные, но никогда не импортируется как Python-код.
