# Capsule E2-S2 — классификатор

Исход: режим выбирается автоматически; нерелевантная задача честно отклоняется.

Зависимости: E2-S1.

Приёмка:

1. В промпт классификатора попадают только `intent` и `description[:250]` валидных скиллов.
2. Материал и тело скилла никогда не входят в classify-запрос.
3. Ответ — маленькая структурированная команда с allowlist-именем или `none`.
4. Неизвестное или невалидное имя даёт тот же пользовательский отказ, что и `none`, без запуска обработчика.
5. Одинаковый intent при температуре 0 даёт стабильный выбранный класс.

Риски: happy, deny, invalid, attack, replay. Concurrency: N/A — чистый select по снимку.

Claims: `src/skillhub/classifier/`, `tests/classifier/`; `classifier.select`, `classifier.allowlist`.

Запрещено: material в промпте, запуск handler, пакеты E3, правка `skills/meeting-protocol/`.
