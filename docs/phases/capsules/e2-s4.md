# Capsule E2-S4 — окно ассистента и classifier matrix

Исход: пользователь видит основной сценарий и факт автоматического выбора.

Зависимости: E2-S3.

Приёмка:

1. Поля «Что нужно сделать» и «Материал для обработки»; состояния loading/error/success/none.
2. Badge выбранного режима; список режимов только для чтения, без ручного selector.
3. `POST /api/assistant` принимает intent и material, защищён CSRF и same-origin.
4. Четыре простых режима и `none` демонстрируются; `meeting-protocol` показывает бейдж и `handler_unavailable`.
5. Минимум 30 размеченных запросов; общая точность матрицы не ниже 95%, неизвестных имён нет.

Риски: happy, deny, invalid, attack, UX empty/error. Concurrency: N/A для вкладки; сервер повторяет проверки.

Claims: `src/skillhub/web/assistant_routes.py`, `src/skillhub/web/_assistant_guard.py`, `src/skillhub/web/static/assistant.js`, `src/skillhub/web/templates/_assistant.html`, `eval/classifier_matrix.md`, `docs/phases/epic-e2-classifier-assistant.md`; `web.assistant-http`, `web.assistant-ui`, `eval.classifier-matrix`.

Shared sequential в этом слайсе: `src/skillhub/web/__init__.py`, `src/skillhub/web/templates/home.html`, `src/skillhub/app_factory.py`, `tests/test_web.py`, `plan.md`, `README.md`.
