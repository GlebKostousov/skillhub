# Capsule E6-S3 — воспроизводимая поставка

Исход: локальный и CI gate совпадают; контейнер non-root multi-stage без ключа и dev-зависимостей; cold start совпадает с README.

Зависимости: E6-S1, E6-S2.

Приёмка:

1. Workflow повторяет `ruff check`, `ruff format --check`, `mypy src tests`, `lint-imports`, `pytest` и падает при покрытии < 85%.
2. Есть dependency audit и secret scan.
3. Финальный stage без dev-группы, `.git` и `DEEPSEEK_API_KEY`.
4. Процесс в образе — `skillhub.main:app`; healthcheck бьёт в `127.0.0.1` внутри контейнера.
5. `uv.lock` pinned; в CI — `uv sync --frozen`.

Риски: happy, deny, invalid, attack. Replay: N/A. Concurrency: N/A.

Claims: `.github/workflows`, `Dockerfile`, `.dockerignore`, `tests/delivery`; `ci.superset-of-local-gate`, `ci.dependency-audit`, `ci.secret-scan`, `docker.non-root-multistage`, `docker.no-key-no-dev`, `docker.healthcheck-readonly`, `delivery.pinned-lockfile`.
