# Capsule E2-S1 — изолированный шлюз модели

Исход: приложение безопасно вызывает DeepSeek через одну типизированную границу.

Зависимости: нет.

Приёмка:

1. Успешный ответ поставщика становится `LlmResult` с текстом, `finish_reason` и фактическим usage.
2. Каждый ошибочный ответ, таймаут и не-stop finish reason становятся типизированным отказом.
3. Ключ и content не попадают в логи и исключения.
4. URL и имя модели задаются только константами пакета `llm`.
5. `FakeLlmGateway` доступен как публичный тестовый шов; production его не выбирает по HTTP.

Риски: happy, deny, invalid, replay, attack. Concurrency: N/A — один процессный вызов без общего mutable cache.

Claims: `src/skillhub/llm/`, `tests/llm/`, `pyproject.toml`, `uv.lock`, `.importlinter`, `src/skillhub/app_factory.py`; `llm.gateway`, `llm.deepseek-http`, `llm.fake-gateway`.

Запрещено: `protocol/`, `docx_export/`, `usage/`, `core/settings.py`, `web/routes.py`, `skills/meeting-protocol/`.
