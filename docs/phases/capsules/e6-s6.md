# Capsule E6-S6 — старт образа с тарифами

Исход: `skillhub.main:app` в контейнере находит `config/model-tariffs.yaml` и отвечает на `GET /health`.

Зависимости: E6-S5. Закрывает finding UR-E6-S3-02.

Приёмка:

1. Runtime-слой копирует исходники или иначе резолвит тарифы так, что `parents[2]` от `app_factory` либо рабочий `/app/config` совпадают.
2. `--no-editable` без `src` не оставляет тарифы только в `/app/config` при поиске рядом с site-packages.
3. Тест в `tests/delivery/` фиксирует этот инвариант по тексту Dockerfile.
4. `ruff format --check .` остаётся 0.

Риски: happy, deny. Attack: ключ по-прежнему не в образе.

Claims: `Dockerfile`, `tests/delivery`; `docker.tariff-layout`.

Запрещено: менять `app_factory.py`, класть ключ, расширять TrustedHost.
