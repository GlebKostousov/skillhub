# Capsule E6-S1 — защита границ

Исход: XSS, CSRF, oversize, path traversal и unknown handler дают контролируемый отказ без утечки пути, prompt и ключа.

Зависимости: нет.

Приёмка:

1. У каждого из пяти классов атак есть отдельный тест в `tests/security/`.
2. Ответ, лог и исключение не содержат абсолютный путь, prompt и значение ключа.
3. Существующие гарды усиливаются только после красного теста.
4. Пакет `skillhub.security` не появляется.

Риски: happy, deny, invalid, attack. Replay: N/A — CSRF одноразовый на экземпляр, не replay-токен. Concurrency: N/A — проверки на одном запросе.

Claims: `tests/security`, `src/skillhub/web/security.py`, `_boundaries.py`, `_host_guard.py`, `_reload_guard.py`, `_assistant_guard.py`, `errors.py`, `protocol_routes.py`, `static/assistant.js`, `static/protocol.js`, `templates`, `registry/_filesystem.py`, `assistant/_registry.py`, `docx_export/_sanitize.py`, `core/_redaction.py`; `http.csrf-same-origin`, `http.trusted-host`, `http.csp-headers`, `http.body-limits`, `http.error-envelope-no-leak`, `ui.no-raw-html`, `registry.symlink-traversal`, `assistant.unknown-handler`, `secrets.env-only`.

Запрещено: `skillhub.security`, `eval/`, `.github/`, `Dockerfile`, перепись `tests/test_web.py` и E1 QA, authn/authz, `app_factory.py`, `README.md`.
