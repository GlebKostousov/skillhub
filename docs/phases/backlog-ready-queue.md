# Backlog / Ready Queue

Дата: 2026-09-12

## Правило очереди

Одновременно открыт один эпик. Параллельный запуск допускается только для явно независимых пар и после разделения зон владения.

## Очередь

1. `E4` Уточнения и качество протокола — ready после E3; открывается по явной команде.
2. `E5` Стоимость и наблюдаемость — ready после E2; открывается по явной команде.
3. `E6` Защита и поставка — blocked by E1–E5.

Закрытое: `E1`, `E2`, `E3` — `docs/phases/done-registry.md`.

## Feature freeze

После начала E6 новые пользовательские функции попадают в будущий backlog и не расширяют тестовое задание.
