# E2. Автовыбор режима и обычные ответы

Статус: не начат
Вес: 8 единиц
Зависит от: E1

## Результат

Пользователь формулирует задачу и добавляет материал. Классификатор выбирает один из пяти скиллов или `none`. Четыре простых режима возвращают реальный текстовый ответ, выбранный режим виден в интерфейсе.

## Слайс E2-S1. Изолированный шлюз модели — 2 единицы

Ценность: приложение безопасно обращается к DeepSeek через одну типизированную границу.

Входит:

- модельный config и ключ только из окружения;
- httpx adapter;
- типизированные request/result/usage/finish reason;
- timeout и предел выходных токенов;
- Fake gateway как публичный тестовый шов.

Приёмка: успешный и каждый ошибочный ответ поставщика преобразуется в стабильный результат/ошибку; ключ и content не попадают в логи.

## Слайс E2-S2. Классификатор — 2 единицы

Ценность: режим выбирается автоматически, а нерелевантная задача честно отклоняется.

Входит:

- только `intent` и `description[:250]`;
- маленький структурированный ответ;
- allowlist snapshot + разрешённые handlers;
- fail-closed для unknown/invalid/none;
- selected skill в ответе.

Приёмка: материал никогда не попадает в classifier prompt; неизвестное имя не запускает обработчик; одинаковый intent даёт стабильный результат при temperature 0.

## Слайс E2-S3. Общий обработчик простых режимов — 2 единицы

Ценность: перевод, резюме, задачи встречи и деловое сообщение реально работают.

Входит:

- `PromptSkillHandler`;
- тело выбранного `SKILL.md` как доверенная инструкция;
- material как отдельные недоверенные данные;
- plain-text/Markdown результат без инструментов;
- одинаковая обработка finish reason и ошибок.

Приёмка: каждый из четырёх режимов получает собственную инструкцию; HTML отображается как текст; body одного скилла не используется другим.

## Слайс E2-S4. Окно ассистента и classifier matrix — 2 единицы

Ценность: пользователь видит понятный основной сценарий и факт автоматического выбора.

Входит:

- поля «Что нужно сделать» и «Материал для обработки»;
- loading/error/success/none;
- badge выбранного режима;
- read-only список режимов;
- минимум 30 размеченных запросов и confusion matrix.

Приёмка: четыре простых режима и `none` демонстрируются из браузера; общая точность матрицы не ниже 95%, неизвестных имён нет.

## Риски

- Визуальный список не должен превращаться в ручной selector и маскировать ошибки классификатора.
- Generic handler не означает generic permissions: у модели по-прежнему нет инструментов.
