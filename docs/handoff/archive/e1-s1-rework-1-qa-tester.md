## Качество suite

- Оракулы проверяют точные публичные контракты, отсутствие приватных маркеров и корреляцию, а не процент покрытия.
- Unit и HTTP проверки преобладают; отдельные процессы используются только для README-startup, access/exception logs и startup failure.
- Bounds-тест теперь разбирает ограниченный вывод как JSON и сохраняет обязательное поле `event`; удаление лимита или сериализации ломает оракул.
- Cycle-тест различает первый контейнер, повторную ссылку и цикл без ожиданий по времени.
- Skip-link проверяется стандартным HTML-парсером: фокусируемая ссылка ведёт на существующую цель `#content` с `tabindex="-1"`.
- Русские docstrings новых тестовых помощников описывают наблюдаемое поведение; проверки не привязаны к формулировкам внутренних docstrings.
- Exact markers `[REFERENCE]`/`[TRUNCATED]` и русские HTTP-сообщения намеренно фиксируют заявленные машинные и публичные контракты.
