## Проверка

- Штатное приложение проверено в реальном браузере при `1440×900`,
  `390×900` и `320×900`.
- Для отсутствующего и частично корректного каталогов использованы отдельные
  безопасные временные корни вне репозитория.
- Тесты не запускались, production-код не менялся, скриншоты не сохранялись.
- После проверки все три локальных сервера остановлены; слушателей на
  проверочных портах не осталось, временный частичный каталог удалён.

## Наблюдаемый результат

- На `1440×900` показаны ровно пять карточек в стабильном порядке. Сетка имеет
  ритм `3 + 2`: первые три карточки находятся на одной строке, оставшиеся две —
  на следующей.
- На `390×900` и `320×900` карточки складываются в одну колонку. При ширине
  390 document `clientWidth/scrollWidth` равны `375/375`, при ширине 320 —
  `305/305`; выходящих за viewport элементов не найдено.
- Ранее отмеченные цели ввода и навигации имеют высоту `44px`: ссылки
  «Главная» и «Скиллы», поле поиска, «Найти», «Очистить поиск»,
  «Перезагрузить каталог» и CTA «Открыть скиллы».
- Вводный текст сформулирован пользовательским языком: «Ищите режим по
  названию или системному имени».
- Отсутствующий корень показывает alert «Каталог не загружен», объяснение
  «Папка каталога не найдена» и действие «Проверьте настроенную папку skills и
  повторите перезагрузку». Машинный код пользователю не показывается.
- Частичный корень сохраняет пять рабочих карточек и показывает alert
  «Каталог загружен частично», понятное объяснение про отсутствие description
  в `broken-sixth` и конкретное действие с `SKILL.md`. Машинный код также
  скрыт.
- Поиск по подписи `ПЕРЕВОД` возвращает только `text-translation`, а поиск по
  системному имени `MEETING-ACTION` — только `meeting-action-items`.
  Пустой `q=` возвращает пять карточек. Запрос без совпадений показывает
  «Найдено: 0», понятный совет и 44-пиксельную ссылку очистки. Запрос длиннее
  128 символов возвращает 422 с человеческим alert и не отражает длинное
  значение обратно в поле.
- Reload проходит как `POST /skills/reload` → `303` →
  `GET /skills?reload=1`; после загрузки адрес сразу канонизируется до
  `/skills`. Успешный результат получает фокус и имеет `role="status"` с
  `aria-live="polite"`. Частичный результат получает фокус и имеет
  `role="alert"` с `aria-live="polite"`.
- После настоящего refresh и Back одноразовый маркер результата и
  программный фокус не возвращаются. При частичном каталоге постоянное
  предупреждение остаётся видимым, но уже без одноразового result-маркера.
- Skip-link является первым Tab-stop, видим при фокусе с синим outline; Enter
  переводит фокус на `main#content`. Поле, кнопки и ссылки доступны в
  клавиатурном порядке и имеют заметный focus-ring.
- На штатной странице консоль чистая. Единственная ошибка за всю браузерную
  сессию — ожидаемый `Failed to load resource: 422` для намеренно длинного
  query. HTML приложения объявляет только локальные Bootstrap, `app.css`,
  `app.js` и favicon; они отвечают 200. Внешние запросы `gc.kis...` создало
  установленное браузерное расширение, они не объявлены приложением и не
  считаются продуктовой находкой.
