## flow

- Root сразу показывает один `h1` «SkillHub», статус «Приложение работает» и CTA «Открыть скиллы». Переход открывает `/skills`.
- Чистый каталог показывает ровно пять карточек в стабильном порядке: `business-message`, `meeting-action-items`, `meeting-protocol`, `text-summary`, `text-translation`. На `1440×900` сетка имеет ритм `3 + 2`; горизонтального overflow нет.
- Поиск по подписи `ПЕРЕВОД` возвращает только `text-translation`. Поиск по системному имени `MEETING-ACTION` возвращает только `meeting-action-items`; `/api/skills?q=MEETING-ACTION` совпал с UI.
- Значение запроса остаётся в поле; ссылка «Очистить поиск» возвращает пять карточек.
- Успешный reload: нажатие «Перезагрузить каталог» приводит на канонический `/skills` (маркер из адреса снят), фокус на `#reload-result`, текст «Каталог перезагружен. Загружено: 5. Пропущено: 0.», пять карточек без дублей. После настоящего refresh одноразовый результат исчез, фокус на `body`, повторного POST нет.
- Отказ reload проверен как пользовательский сценарий: ёмкость из восьми одноразовых результатов заполнена same-origin POST без перехода по redirect, затем обычное нажатие «Перезагрузить каталог». Страница каталога сохранилась. Alert: «Каталог пока не перезагружен» / «Перезагрузка каталога сейчас недоступна.»; действие «Вернуться к каталогу»; кнопка «Перезагрузить каталог» остаётся для повтора. Сырого JSON и кода `reload_unavailable` нет. Адрес после загрузки — канонический `/skills`.
- «Вернуться к каталогу» снимает notice и оставляет пять карточек. HTTP `GET /skills?notice=reload-unavailable` отвечает `200 text/html` с тем же каталогом, alert и skip-link, без машинного кода.
- На `320×900` `clientWidth` и `scrollWidth` равны `305px`, выходящих элементов нет, карточки в одну колонку шириной `281px`. Notice, возврат, поле, кнопки и навигация имеют высоту `44px`.

## states

- Success: root, полный каталог из пяти карточек и успешный reload с одноразовым status видны и понятны.
- Loading: перед отправкой reload кнопка становится disabled и меняется на «Перезагрузка…»; скрытый `role="status"` получает «Каталог перезагружается.» Поведение не регрессировало.
- Empty: N/A для этой дельты — штатный каталог не пуст; пустой поиск не менялся.
- Partial: постоянное предупреждение частичной загрузки в дельте не ломалось; одноразовый успешный reload по-прежнему отделён от notice.
- Error / unavailable: отказ reload больше не заменяет каталог JSON-страницей. Пользователь остаётся на каталоге с человеческим alert и явным возвратом; повтор доступен той же кнопкой reload.
- Offline: N/A — недоступность процесса показывает браузер.
