## flow

- README сохраняет одну явную команду запуска: `uv run python -m skillhub --port 8000`; `.env` и `DEEPSEEK_API_KEY` не нужны.
- Root по-прежнему сразу показывает единственный статус «Приложение работает», а `/health` возвращает `{"status":"ok"}`.
- Если ошибка возникает до начала ответа, клиент получает русский JSON-ответ 500. Если заголовки уже отправлены, заменить ответ на 500 невозможно: теперь сервер явно обрывает передачу, и клиент видит незавершённое тело вместо принятия частичного ответа как завершённого.
- README заменяет англоязычные служебные формулировки на понятные «привязывает сервер», «журнал доступа» и «события запуска»; команда, адреса root/health и локальная область доступа остаются однозначными.

## states

- Success: root и `/health` доступны после одной документированной команды.
- Error до начала ответа: 400, 404, 405 и 500 имеют стабильные русские оболочки.
- Error после начала ответа: соединение завершается как неуспешная передача; клиент наблюдает `IncompleteRead`, а не полное частичное тело.
- Loading и empty: N/A — в E1-S1 нет асинхронной загрузки или пользовательского набора данных.
- Offline: N/A — клиентского runtime нет; недоступность локального процесса отображает браузер.

## errors/API

- Сохранены русские сообщения: 400 — «Некорректный запрос.», 404 — «Запрошенные данные не найдены.», 405 — «Метод запроса не поддерживается.», 500 — «Внутренняя ошибка сервера.».
