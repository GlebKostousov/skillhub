## Пройденные сценарии

- Обычный поиск по подписи `ПЕРЕВОД` вернул только `text-translation`; поиск
  по системному имени `MEETING-ACTION` при ширине 320 вернул только
  `meeting-action-items`.
- На `1440×900` пять карточек сохранили стабильный порядок и сетку `3 + 2`;
  горизонтального overflow нет.
- На `320×900` `clientWidth` и `scrollWidth` равны `305px`, выходящих за
  viewport элементов нет, карточки сложены в одну колонку шириной `280.8px`.
  Навигация, поле, кнопки и ссылка очистки имеют высоту `44px`.
- Сохранены `lang="ru"`, именованная навигация, один `main`, один `h1`,
  подпись searchbox и live-статус количества результатов.
- Skip-link остаётся первым Tab-stop, видим с синим outline `3.2px`; Enter
  переносит фокус на `main#content`.
- Успешная перезагрузка прошла как `POST /skills/reload` → `303` →
  `GET /skills?reload=<43-символьный marker>` → `200`. После загрузки адрес
  стал каноническим `/skills`, фокус оказался на `#reload-result`, а результат
  имел `role="status"` и `aria-live="polite"`.
- После настоящего refresh канонического `/skills` одноразовый результат
  исчез, фокус вернулся на `body`, повторного POST не было. Прямой replay
  потреблённого marker также не показал старый результат и не вернул
  программный фокус.
- В штатном сценарии и после successful reload ошибок и предупреждений
  консоли не было.

## P2 — отказ reload выводит сырой JSON вместо понятного состояния каталога

Ёмкость из восьми одноразовых результатов была детерминированно заполнена
same-origin запросами из реального браузера без перехода по redirect. После
этого обычное нажатие «Перезагрузить каталог» привело на
`/skills/reload` с видимым ответом:

`{"error":{"code":"reload_unavailable","message":"Перезагрузка каталога сейчас недоступна. Повторите позже."}}`

Текст сообщения безопасен и сам по себе понятен, но пользователь полностью
теряет интерфейс SkillHub: у страницы нет title, `main`, `h1`, app-навигации,
`role="alert"`, live-region и ссылки или кнопки возврата. Фокус остаётся на
`body`, наружу показан машинный код `reload_unavailable`, а вернуться к
каталогу можно только средствами браузера.

Это видимая interaction-проблема: тот же ответ доступен при занятом reload
gate или заполненной ёмкости. Ожидается сохранение страницы каталога с
человеческим alert/status и явным действием «Повторить позже» либо
«Вернуться к каталогу».
