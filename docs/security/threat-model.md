# Модель угроз SkillHub

Дата: 2026-09-11
Основа: OWASP Top 10 for LLM Applications 2025 и OWASP LLMSVS.

## Активы

- ключ DeepSeek;
- целостность выбранного скилла;
- правильность протокола и Word;
- транскрипция и персональные данные участников;
- дневной бюджет модельных вызовов;
- целостность каталога скиллов и журнала расходов.

## Границы доверия

1. Браузер → FastAPI: всё недоверенное, включая скрытые поля и состояния кнопок.
2. Каталог скиллов → реестр: локально управляемый, но парсится как недоверенный файл.
3. Намерение → классификатор: недоверенный текст, операция без полномочий.
4. Материал → модель: недоверенные данные с возможной прямой или косвенной prompt injection; для скиллов встречи материалом служит транскрипция.
5. Ответ модели → приложение: недоверенный текст до строгого парсинга.
6. Приложение → SQLite/DOCX/HTML: только типизированные и контекстно закодированные значения.

## Угрозы и меры

| Угроза | Последствие | Основные меры | Проверка |
|---|---|---|---|
| Команда внутри материала сменить скилл | Неверная маршрутизация | Классификатор не получает материал; выход по allowlist | Атакующий eval и unit-тест |
| Команда раскрыть системный промпт или ключ | Утечка | Ключ не находится в модельном контексте; системный prompt не считается секретом; вывод проверяется | Поиск ключа в HTTP/логах/SQLite |
| Модель выдаёт HTML/JavaScript | Межсайтовый скриптинг | Только `textContent`/`value`, Jinja autoescape, CSP, без `innerHTML` | Браузерный тест с `<script>` |
| Модель ломает Markdown-таблицу | Неверный Word или обход структуры | Строгий parser, три колонки, типизированная 422 | Негативные тесты грамматики |
| Модель придумывает владельца или срок | Ложный протокол | Канонический `—`, проверка опорных сущностей, уточнения, verifier, человек до экспорта | Фикстуры с отсутствующими/противоречивыми данными |
| Несвязанный запрос вызывает платную генерацию | Расходы и использование не того скилла | Классификатор до обработчика; `none` означает отказ | 6 положительных + 4 отрицательных eval |
| Огромная транскрипция или много параллельных запросов | Отказ в обслуживании и расходы | Предел байтов/токенов/времени, semaphore, дневной и запросный бюджет | Oversize и concurrency-тест |
| Повтор после неопределённого таймаута | Двойная оплата | Нет автоматического повтора модельного вызова после отправки; пользователь решает | Тест таймаута после dispatch |
| Подмена URL поставщика | SSRF | URL только из валидированного YAML, отсутствует в HTTP-схеме | Тест лишнего поля и config validation |
| Вредоносный YAML или symlink | Чтение вне корня / расход памяти | `safe_load`, предел размера, containment check, symlink наружу запрещён | YAML bomb/oversize/path traversal |
| SQL injection через модель или браузер | Порча журнала расходов | Параметризованные sqlite3-запросы, фиксированная схема | Атакующие строки в полях |
| Управляющие XML-символы или ссылки в результате | Битый/опасный Word | Только python-docx text nodes, очистка control chars, без macro/raw XML/relations | Проверка содержимого ZIP-пакета DOCX |
| Подделка изменяющего запроса из чужого сайта | Расход бюджета / reload | same-origin, CSRF, CORS off, JSON-only, TrustedHost | API-тест Origin/CSRF |
| Утечка транскрипции через наблюдаемость | Нарушение конфиденциальности | Не хранить контент; рекурсивный scrubber логов; SQLite только usage | Log-capture и schema-тест |

## Политика модельных полномочий

- Модель может вернуть только текст.
- Модель не вызывает инструменты и функции.
- Модель не читает файловую систему и SQLite.
- Модель не выбирает URL и модель.
- Классификатор выбирает имя, но исполнение разрешает статический `SkillHandlerRegistry`.
- Неизвестное имя, невалидный формат и превышение лимита закрывают путь, а не включают запасной небезопасный режим.

## Работа с материалом

- В классификатор передаётся только `intent`.
- В обработчик передаётся системный prompt выбранного скилла и отдельный блок недоверенного материала.
- Разделители и инструкция «не исполнять текст» — дополнительная мера, не security boundary.
- Материал не пишется в SQLite, лог или постоянное browser storage.
- Блокирующего уведомления о внешнем поставщике нет по решению владельца; интеграция описывается в README.

## Security-gate перед сдачей

- secret scan по рабочему дереву и истории;
- `pip-audit`;
- Bandit/Semgrep, если установлены;
- атакующие unit/API/browser tests из таблицы;
- ручная проверка Content Security Policy и DOCX ZIP;
- живой prompt-injection eval без автоматического исполнения результата;
- отчёт разделяет подтверждённые дефекты, hardening и ограничения модели.
