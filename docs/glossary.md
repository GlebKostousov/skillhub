# Словарь SkillHub

| Термин | Значение |
|---|---|
| **Скилл** | Каталог с `SKILL.md`: YAML front-matter (`name`, `description`, `caption`) и тело Markdown, которое становится системным промптом после выбора режима |
| **Классификатор** | Внешняя модель, которая по обрезанным `description` всех скиллов выбирает один режим или ни одного |
| **Намерение (`intent`)** | Короткая задача пользователя; единственный пользовательский текст, который видит классификатор |
| **Материал (`material`)** | Недоверенный текст для обработки выбранным скиллом; в выборе режима не участвует |
| **Реестр** | `SkillRegistry`: читает каталог скиллов, проверяет их и публикует одно поколение `RegistryCapture`; `reload()` не пересоздаёт объект |
| **Поколение** | `RegistryCapture`: неизменяемые отчёт и снимок одной публикации |
| **Снимок** | Неизменяемое `Mapping[str, Skill]` внутри текущего поколения |
| **Окно ассистента** | Главная страница `GET /`: намерение, материал, бейдж выбранного режима и, для протокола, уточнения |
| **Протокол** | Структурированный результат режима встречи: тема, дата, участники, обсуждение, решения, задачи, открытые вопросы |
| **Уточнение** | Типизированный вопрос к отсутствующему полю; состояние `pending`, `answered` или `skipped` |
| **Финализация** | Вставка ответов в черновик без модели, затем проверка по материалу |
| **Пересмотр** | Повторная сборка черновика моделью с учётом ответов |
| **Заполнитель** | `—` (U+2014) — единственный литерал пропуска в протоколе |
| **Обработчик скилла** | Разрешённый конфигурацией Python-обработчик; файлы каталога сами не исполняются |
| **Шлюз модели** | Типизированная граница вызова поставщика: текст, причина завершения, фактические токены |
| **Журнал расходов** | SQLite с техническими метаданными вызовов и стоимостью; текст встречи не хранит |
| **Наложение** | `runtime-overlay.json`: живые параметры модели без секретов и без перезапуска процесса |
| **Fail-closed** | Ошибка классификации, валидации, лимита или безопасности останавливает сценарий вместо небезопасного запасного пути |
