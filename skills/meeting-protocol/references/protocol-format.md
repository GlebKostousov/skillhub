# Формат протокола v1

Результат содержит разделы только в указанном порядке:

```markdown
# Протокол встречи: <тема>

**Дата:** <YYYY-MM-DD | —>
**Участники:** <имена через запятую | —>

## Обсуждение
- <пункт обсуждения>

## Решения
- <принятое решение>

## Задачи
| Задача | Ответственный | Срок |
|---|---|---|
| <формулировка> | <имя | —> | <YYYY-MM-DD | исходный текст срока | —> |

## Открытые вопросы
- <что не удалось определить и почему>
```

## Ограничения структуры

- Допускается ровно один заголовок первого уровня с префиксом
  `Протокол встречи:`.
- Строки даты и участников следуют сразу за заголовком в заданном порядке.
- Заголовки второго уровня не переименовываются и не переставляются.
- Пустой раздел обозначается единственным пунктом `- —`.
- Таблица задач содержит ровно три колонки. Символ `|` внутри значения
  заменяется на `/`.
- Единственный литерал неизвестного значения — `—`.
- Относительный срок преобразуется в дату только при известной дате встречи;
  иначе сохраняется дословно.

## Проверка утверждений

Обсуждение не равно решению. Функция `verify` детерминированно отмечает
неподтверждённые решения, задачи, сроки и ответственных: в материале ищутся
явные маркеры подтверждения рядом с формулировкой пункта. Модель не
вызывается. Противоречие и атакующая фраза не повышают статус утверждения.
